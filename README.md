# Laravel Tips

**All credit for this collection goes to [Dipesh Sukhia](https://dipeshsukhia.github.io/).**

A searchable collection of 358 Laravel tips across 14 categories. The site renders the Markdown files in `knowledge-base/` as static pages, with searchable tip lists and copyable code snippets.

Browse the [knowledge base](knowledge-base/) to view the source Markdown files by category.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000/laravel-tips/` in your browser.

## Build and publish

Run `npm run build` to export the site into `docs/`. GitHub Pages serves the `main` branch from `/docs`; commit the generated `docs/` output along with source changes to publish an update.
