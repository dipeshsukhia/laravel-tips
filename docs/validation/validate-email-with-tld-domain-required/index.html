Validate Email with Tld Domain Required.

By default, the email validation rule will accept an email without tld domain (ie: user@laravel)

But if you want to make sure the email must have a tld domain (ie: user@example.com), use email:filter rule.

php
[
    'email' => 'required|email', // before
    'email' => 'required|email:filter', // after
],
